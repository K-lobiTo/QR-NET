Layers & grading weight
OSI Layer 1
Physical — DispositivoLuzAdaptador
20%
  • QR code over light / camera
  • Max frame size: 128 bytes
  • CRC-16 checksum
  • Medium access control (CSMA)
  • Protocol version field
  • MAC-analogous physical address
  • Library: DispositivoLuzAdaptador
OSI Layers 2 & 3
Network — remote-QR-net
30%
  • Anonymous mesh over TCP/IP
  • Sender anonymity (no origin leak)
  • Dynamic routing through mesh
  • Virtual circuits (pre-negotiated)
  • Node directory service
  • Channels: Ethernet, WiFi, QR, Video
  • Scapy allowed
OSI Layer 7 — Anonymous
Microblog / Chat (QR-NET only)
10%
  • Microblogging within QR-NET
  • Anonymous chat between peers
  • Content never leaves QR-NET
OSI Layer 7 — Public
Clearnet Bridge (IRC + NNTP)
10%
  • Known IRC server install
  • IRC bot bridges QR-NET ↔ clearnet
  • Only public-tagged posts exit
  • New topic entry → NNTP article
